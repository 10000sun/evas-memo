    사용 방법

    기본 사용법

    • 개인 메모는 나만 보고, 공동 메모는 로그인한 모든 사람이 보고 고칩니다.
    • 새 메모는 위쪽 + 메모를 누릅니다. 지금 보고 있는 탭(개인·공동)에 만들어집니다.
    • 메모를 누르면 편집 화면이 열립니다. 본문은 치는 대로 저장되고, 같은 메모를 연 사람의 커서와 이름이 사람마다 다른 색으로 보입니다.
    • 본문은 마크다운(# 제목, **굵게**, - [ ] 할 일, 표 등)으로 쓸 수 있고, 오른쪽 위 미리보기를 누르면 꾸며진 모양으로 봅니다.
    • 본문 속 주소 뒤의 ↗를 누르면 새 탭으로 열립니다(PC는 Ctrl+클릭도 됩니다). 본문에서 Tab은 띄어쓰기 4칸이고, 키보드로 본문을 벗어나려면 Esc를 누른 뒤 Tab을 누릅니다.
    • 위쪽 분류 이름을 누르면 그 분류 메모만 보입니다. 다시 누르면 풀립니다. 검색칸은 제목과 본문을 찾습니다.
    • 개인 메모의 공동으로 옮기기는 메모를 공동으로 옮깁니다(개인 쪽에는 남지 않음). 공동 메모의 개인으로 복사는 내 개인 메모로 사본을 만듭니다(원본은 그대로).
    • 다른 사람이 바꾼 목록은 20초마다 자동으로 반영되고, 바로 보려면 새로고침 버튼을 누릅니다.
    • 종 아이콘에서 공동 메모 작성·수정·삭제 내역을 볼 수 있고, 안 읽은 것이 있으면 빨간 점이 켜집니다.

    휴대폰 메모앱으로 내보내기

    • 편집 화면의 내보내기를 누르면 휴대폰 공유창이 열립니다. 메모(아이폰) 또는 기본 메모앱을 고르면 제목과 본문이 들어갑니다.
    • 공유창이 없는 PC에서는 제목과 본문이 클립보드에 복사되고, 복사도 막혀 있으면 .txt 파일로 저장됩니다.

    홈 화면에 추가

    아이폰 (Safari로 열어야 합니다)

    1. 화면 아래 공유 버튼(네모에 위쪽 화살표)을 누릅니다.
    2. 홈 화면에 추가를 누르고 추가를 누릅니다.

    안드로이드 (Chrome)

    1. 오른쪽 위 메뉴(점 세 개)를 누릅니다.
    2. 홈 화면에 추가 또는 앱 설치를 누르고 안내에 따라 추가합니다.

    알림 받기

    1. 아이폰은 홈 화면에 추가한 앱 아이콘으로 열어야 합니다. Safari 탭에서는 켤 수 없습니다. (iOS 16.4 이상)
    2. 위쪽 종 아이콘을 누르고 이 기기 알림 켜기를 누른 뒤 허용을 선택합니다.
    3. 다른 사람이 공동 메모를 새로 쓰거나 지우면 폰에 알림이 옵니다. 내가 한 것과 개인 메모는 알림이 오지 않습니다.

    허용 창을 거절했다면 아이폰은 설정 → 알림 → 에바스 메모, 안드로이드는 앱 정보 → 알림에서 켭니다. 켜는 버튼이 보이지 않으면 관리자에게 알림 설정을 요청하세요.
