분류

색은 모든 사용자에게 똑같이 보입니다. 이름과 색은 관리자만 바꿉니다. 분류를 지우면 그 분류의 메모는 ‘미분류’가 됩니다(메모는 지워지지 않음). 색은 견본을 누르거나 HEX(#3b5bdb), RGB(59, 91, 219)로 직접 입력하세요.

사용자 권한

관리자는 분류와 사용자 권한을 관리합니다. 사용자 ID는 디스코드 ID입니다.

접속한 사용자

‘차단’은 그 사람의 디스코드 계정과 쓴 기기를 막고 캘린더에도 적용됩니다(관리자는 먼저 권한을 내려야 합니다). 디스코드로 한 번이라도 접속한 사람이 자동으로 올라옵니다. 처음 접속하면 편집자로 등록되고 관리자는 여기서 지정합니다. ‘기본값으로’를 누르면 지정이 지워집니다.

백업·복구

백업은 지금의 모든 데이터(DB 파일 하나)를 내려받습니다. 복구는 고른 백업 파일로 지금 데이터를 통째로 덮어씁니다. 복구 직전의 데이터는 서버에 .before-restore 파일로 한 부 남습니다. 백업에는 사용자 ID·차단 목록이 들어 있으니 안전한 곳에만 보관하세요.

자동 백업: 하루에 한 번 만들고 최근 7개만 남깁니다(넘으면 오래된 것부터 지움).
