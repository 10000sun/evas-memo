# evas-memo

팀이 함께 쓰는 공동 메모 웹앱. 메모별 실시간 공동 편집, 분류(색), 폴더, 마크다운, 디스코드 로그인, 웹에서 편집 권한 관리, 활동 기록·푸시 알림, 메모 내보내기.

## 기능
- **공동 편집**: 같은 메모를 여러 사람이 동시에 고친다. 다른 사람의 커서는 사람마다 다른 색으로 이름과 함께 보이고, 같이 접속한 사람과 색이 겹치면 빈 색으로 자동으로 바뀐다(색은 사용자별로 정해지며 직접 고르지는 않는다).
- **마크다운**: 본문은 마크다운 원문으로 쓰고(입력 중 문법 강조), `편집 | 미리보기`로 꾸며진 모양을 본다. 목록에서 Enter를 치면 다음 항목이 이어지고(번호는 +1, 빈 항목에서 Enter로 해제), Tab은 공백 4칸(여러 줄을 고르면 들여쓰기, Shift+Tab은 내어쓰기), 되돌리기(Ctrl+Z)는 **내가 한 편집만** 되돌린다(다른 사람이 쓴 글은 지워지지 않는다). 미리보기는 무해화된 HTML이고 링크는 새 탭으로 열린다. 빈 줄로 나뉜 한 문단이 6000자를 넘으면 느려지지 않게 그 문단만 앞 6000자까지 그리고 안내 문구를 붙이며(짧은 문단만 있으면 아무리 길어도 자르지 않는다), 서식 기호가 유난히 많은 문단이 쌓이면 뒤쪽은 서식 없이 글 그대로 보여 준다(전체는 편집 화면과 내보내기에 그대로 있다).
- **폴더**: 개인 메모는 각자 자기 폴더(본인만 보임), 공동 메모는 공동 폴더에 넣는다. 폴더 안에 하위 폴더 한 단계까지(2단계). 목록 위 폴더 줄에서 고르고 만들고 이름을 바꾸거나 지운다(지워도 메모는 '폴더 없음'으로 남는다). 공동 폴더는 편집자 이상이 만들고 이름을 바꾸며, 지우기는 만든 사람과 관리자만.
- **`@` 태그**: 본문에서 `@`를 치면 커서 위쪽에 후보 목록이 뜬다. 캘린더 일정(캘린더 연동을 켠 경우)과 메모(공동·본인 개인)를 고르면 `[@제목](주소)` 링크가 들어가고, 편집 화면 본문 위의 연결 칩에 모여 누르면 그 일정·메모로 간다. 지워진 대상은 '삭제됨'으로 보인다.
- **전율(관리자 전용)**: 관리자 역할 전원이 함께 보고 고치는 세 번째 메모 탭. 관리자가 아니면 탭·메모·폴더가 목록·검색·주소·태그 어디에도 드러나지 않는다(없는 것처럼 404). **활동 기록·푸시 알림이 없고 캘린더로도 나가지 않는다**(캘린더에서 태그할 수 없다). 관리자는 편집 화면에서 개인·공동 메모를 `전율로 옮기기`, 전율 메모를 `공동으로 옮기기`·`개인으로 옮기기`(복사가 아닌 이동, 폴더는 비움)할 수 있다. 옮겨져 접근을 잃는 사람의 편집 창은 삭제됐을 때와 같은 문구로 닫혀 옮겨졌다는 사실이 드러나지 않는다. 전율 메모 본문의 `@`는 공동·본인 개인·전율 메모를 모두 고른다. 관리자에서 내려가면 열려 있던 전율 편집이 바로 닫힌다. 마지막으로 연 탭을 기억하는 브라우저 저장소에는 전율 탭을 기록하지 않는다.

## 실행 (Windows 서버)
1. `python -m pip install -r requirements.txt`
2. `.env.example`을 `.env`로 복사해 채운다 (`.env`는 깃에 안 올라가므로 수동 복사)
3. `python -m uvicorn app.main:app --host 127.0.0.1 --port 8001`
4. 바깥에서 접속: [docs/DEPLOY.md](docs/DEPLOY.md) (포트포워딩 + DuckDNS + Caddy HTTPS)

데이터는 `data/evas.db`(깃 제외). 백업은 이 파일을 복사하면 된다.

## 꼭 지킬 것
- **단일 프로세스**: uvicorn 워커는 **1개**로만 띄운다(`--workers` 금지). 공동 편집 문서를 프로세스 메모리에 들고 있어서, 워커가 여러 개면 사람마다 다른 문서를 보게 된다.
- **서버 시간대는 한국(KST)** 이어야 화면의 시각이 맞는다.
- **`SESSION_SECRET`은 `.env`에 반드시 고정**한다. 비우면 재시작할 때마다 새 값이 만들어져 모두 로그아웃되고 편집 중이던 입력을 잃을 수 있다.
- **`EVAS_DEV_AUTH`는 운영 `.env`에 넣지 않는다.** 로그인 없이 신원을 헤더로 지정할 수 있는 개발·테스트용 우회 수단이다.
- 휴대폰에서의 내보내기(공유·저장)는 **HTTPS에서만** 동작한다. 운영은 Caddy HTTPS로 접속한다.

## 디스코드 로그인 설정
개발자 포털에서 애플리케이션을 만들고 OAuth2 > Redirects에 `PUBLIC_URL/auth/callback`을 등록한다. 봇은 필요 없다.

## 푸시 알림(선택)
`python scripts/make_vapid.py` 출력 세 줄을 `.env`에 붙여 넣는다. 한 번 정하면 바꾸지 않는다(바꾸면 기존 구독이 모두 무효).

## 캘린더 연동(선택)
`@`로 캘린더 일정을 태그하고, 캘린더에서 공동 메모를 태그하고, 헤더의 `에바스 캘린더 | 에바스 메모`로 두 앱을 오간다(개인·전율 메모는 캘린더로 나가지 않는다). 설정은 [docs/DEPLOY.md](docs/DEPLOY.md)의 "캘린더 연동 설정" 한 곳에 모아 뒀다. 요점: 두 앱 `.env`에 같은 `LINK_API_KEY`, 메모는 `CALENDAR_URL`, 캘린더는 `MEMO_URL`. `LINK_API_KEY`가 비면 캘린더 일정 태그만 꺼진다.

## 테스트와 번들
- 서버: `python -m pytest`
- 브라우저 코드(`static/memolink.js` 등)는 pytest가 `node --test tests/memolink.test.js`도 돌린다(node가 없으면 건너뜀).
- 에디터·미리보기 번들(`static/vendor/*.bundle.js`)은 `tools/`에서 빌드한 결과를 커밋한다: `cd tools && npm i && npm run build`, 미리보기 테스트는 `node test-markdown.mjs`. `tools/node_modules`는 커밋하지 않는다.
