# evas-memo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** evas-calendar와 같은 기능·화면 구성의 팀 메모 웹앱(개인/공동, 분류, 실시간 공동 타이핑, 다크/라이트).

**Architecture:** FastAPI + SQLite + 프레임워크 없는 JS. 메모 본문은 Yjs 문서이고 서버는 `pycrdt`로 문서를 메모리에 들고 WebSocket(`/ws/memos/{id}`)으로 중계, 상태를 SQLite `memos.ydoc`에 저장한다. 브라우저는 CodeMirror 6 + `y-codemirror.next`(esbuild 번들을 `static/vendor/`에 커밋). 인증·권한·푸시·PWA·관리자 화면은 `E:\폴더\개발\evas-calendar`에서 복사해 이름만 바꾼다.

**Tech Stack:** Python 3.12, fastapi, uvicorn(1프로세스), pycrdt, pycrdt-websocket, itsdangerous, httpx, pywebpush, pytest / Node(esbuild, 개발 PC에서만), CodeMirror 6, yjs, y-codemirror.next, y-protocols.

**Spec:** `docs/superpowers/specs/2026-10-13-evas-memo-design.md`

## Global Constraints

- 사용자 응답·UI 문구·커밋 메시지·문서는 한글. 브랜치 이름은 소문자 영어+하이픈(`feat/realtime-core`).
- 작업 브랜치 → `develop`. **`main`에는 사용자가 "배포하라"고 할 때만.** 커밋·푸시는 사용자가 요청할 때만(전역 규칙) — 아래 "Commit" 단계는 요청이 있을 때 수행한다.
- 서버는 uvicorn **단일 프로세스**(워커 1). Node는 번들 빌드용이며 서버에 필요 없다.
- 본문 최대 **100,000자**. 분류 색은 `#rrggbb`. 분류 변경 API는 관리자만. 공동 메모 삭제는 작성자·관리자만. 개인 메모는 owner 외 누구에게도(관리자 포함) 비노출.
- 권한 판정은 캘린더와 동일: `users` 표의 role, 없으면 `EVAS_OPEN_EDIT=1`이면 `editor`, 아니면 `viewer`. 메모 작성·편집은 `admin|editor`, 열람(공동)은 로그인한 누구나.
- `EVAS_DEV_AUTH=1`일 때만 `X-User-Id` 헤더 인증(테스트용). 테스트는 `EVAS_DB`로 임시 DB를 쓴다(캘린더 `tests/conftest.py` 방식).

## Review Focus

1. 같은 메모에 두 사람이 같은 위치에 동시에 입력 → 둘 다 보존되고 두 화면이 같은 결과(Task 1·3).
2. 서버 재시작(문서가 메모리에서 사라짐) 직후 다시 열기 → 직전까지의 본문 복원(Task 3).
3. 100,000자 초과 입력/붙여넣기 → 거절·안내, 문서는 손상 없음(Task 3).
4. 로그아웃·다른 사람 세션으로 개인 메모 WebSocket 접속 시도, 존재하지 않는 id → 연결 거절(Task 3).
5. 분류 삭제 후 그 분류 메모 → '미분류'로 남고 목록에서 안 사라짐(Task 2).

### Task 3: 메모 API + 실시간 저장·권한

**Files:**
- Create: `app/memos.py`(라우터), `tests/test_memos.py`, `tests/test_memo_ws.py`
- Modify: `app/ws.py`, `app/main.py`

**Interfaces:**
- Consumes: Task 1 `ws.router`, Task 2 `current_user/editor/admin`, `db.connect`.
- Produces (JSON 필드: `id, kind, owner_id, title, category_id, body_text, created_name, updated_name, updated_at`):
  - `GET /api/memos?kind=personal|shared&category_id=&q=` — personal은 본인 것만. `q`는 제목·본문 부분 일치. 최근 수정순.
  - `POST /api/memos` body `{kind, title, category_id|null}` (editor). `PUT /api/memos/{id}` body `{title?, category_id?}`(열람·편집 가능한 사람). `DELETE /api/memos/{id}` → 204 (공동은 작성자·관리자, 개인은 owner).
  - `POST /api/memos/{id}/share` — personal → shared **이동**(owner만). `POST /api/memos/{id}/copy-to-personal` — shared의 **복사본**을 호출자 소유 personal로 생성하고 새 메모 JSON 반환(원본 불변, ydoc 바이트를 복사해 서로 독립).
  - `ws.can_access(memo_row, user) -> bool`: 공동은 로그인한 누구나(editor 이상이 편집, viewer는 읽기 전용), 개인은 `owner_id == user.id`.
  - `ws.get_doc(memo_id)`: DB의 `ydoc`로 복원한 방. 문서 변경 후 2초 디바운스로 `ydoc`/`body_text`/`updated_*`를 저장하고 마지막 접속자가 나갈 때도 저장. 본문이 100,000자를 넘는 업데이트는 적용하지 않고 해당 연결에 닫기 코드 1009 전송.
